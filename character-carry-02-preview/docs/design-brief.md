# 红衣卡通女孩搬运走路

## 目标

保留用户提供的新 FBX 角色外观、网格、UV 与主贴图，重新按实际结构绑骨，制作双手向前托举、双脚交替走路的无缝循环，不添加道具，不覆盖旧角色文件。

## 角色与制作路线

- 风格：约 1 米高的 Q 版女孩，红色中式服装、双发髻与红色飘带。
- Blender：FBX 导入、39 个连通部件检查、22 根骨骼、蒙皮权重、动作关键帧、原生 `.blend` 与带动画 GLB 导出。
- Three.js / Edit3D：最终 GLB 加载、棚拍灯光、动作时间采样、速度参数与可编辑预览。
- 关节树：root → hips → spine → chest → neck → head；chest → 双臂 upper_arm / forearm / hand；hips → 双腿 thigh / shin / foot；head → pigtail 与 ribbon_tail。
- 动作：`搬运走路_双手前举`，64 帧循环，30 fps，约 2.13 秒。双手不作走路反向摆臂，左右腿在半周期交换，支撑脚与髋部做落地补偿。

## 检查范围

正面、三分之四、侧面、背面；第 1 / 17 / 33 / 49 帧；GLB 回导后的骨架、UV、贴图、权重、循环首尾、腿部换边和双手稳定性。浏览器中另查实际播放、定位、材质卡、速度保存与恢复。
