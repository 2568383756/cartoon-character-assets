# 卡通人物绑骨与预览设计说明

## 目标

将用户提供的卡通人物 FBX 制作成可继续编辑的基础全身绑骨资产，保留原始外观，并提供可旋转、可播放测试动作的 Work 三维预览。

## 要求清单

- 使用 FBX 版本：5,466 个源顶点、10,419 个源三角面、23 个连接部件。
- 保留主贴图、UV、比例与卡通造型，不覆盖用户原文件。
- 22 根骨骼：躯干、头、双臂、双手、双腿、双脚、脑后发带。
- 所有顶点具有归一化蒙皮权重，单个顶点最多 4 个骨骼影响。
- 提供 `.blend` 源文件与带骨架、动画的 `.glb`。
- 预览支持模型选择、材质调整、动作时间轴和三分之四主视角。
- 默认不拆分手指、精细面部骨骼和 IK 控制器。

## 角色结构

- 身高约 1 m，大头部、短四肢，正面朝 Blender 的 -Y。
- 骨骼树：root → hips → spine → chest → neck → head；chest → arm → forearm → hand；hips → thigh → shin → foot；head → ribbon / ribbon_tail。
- 测试动作：1–96 帧，30 fps，包含抬手、左右重心步伐和发带随动。
- 预览附加轻微呼吸和头部摆动；原模型五官合并在单一网格中，不承诺眨眼。

## 材质与灯光

- 角色：用户主贴图，保留导入的 Principled 材质，材质名“卡通人物 · 主贴图”。
- 地面：浅灰哑光，roughness 0.96，仅用于棚拍展示，不参与取景中心计算。
- 主光：左前暖色方向光，带 1024 阴影贴图；右侧冷色补光与后侧轮廓光。
- 色调映射：Neutral，避免帽子和袖口高光过曝。

## 主视角与检查视角

- 主视角：角色正面三分之四，完整显示帽子到鞋底。
- 检查：正面抬手、侧面、背面、步伐中间帧。
- 预览时间轴可定位动作起始、抬手和步伐阶段。

## 可编辑项

- 角色整体变换与主贴图材质。
- 动作速度 0.25–2 倍、呼吸幅度 0–0.04、头部摆动 0–0.08。
- 地面材质、主相机与灯光。

## 制作路由

- Blender：FBX 导入、部件识别、骨架、蒙皮、测试动作、原生文件和 GLB 导出。
- Three.js / Edit3D：棚拍灯光、材质编辑、参数、时间轴和预览。

## 性能

- 单一角色、单一主材质、一张主贴图、一盏投影灯，适合实时旋转和时间轴播放。
